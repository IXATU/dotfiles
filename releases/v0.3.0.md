# v0.3.0 — Agent tooling and terminal UX

**Fecha:** 2026-10-23
**Previous Release:** v0.2.0

## Highlights

- Classic / Lightest Powerlevel10k prompt with full, unshortened paths, repository owner, upstream, Git state, Python/uv and author indicators preserved.
- Docker cleanup aliases no longer invoke the engine at Zsh startup and use confirmed pruning rather than deleting all images.
- Cursor Agent CLI and Herdr managed reproducibly through dotfiles.
- Serena runtime settings and Azure MCP dependencies stabilized on the WSL workstation.
