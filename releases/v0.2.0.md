# v0.2.0 — Workstation baseline cleanup

**Fecha:** 2026-09-22  
**Previous Release:** v0.1.0

## Highlights

- Node 24 is now the workstation baseline while preserving Node >=22 as the compatibility floor for managed AI tooling.
- Gitleaks is managed through the official GitHub release channel with SHA-256 verification and participates in the workstation update snapshot.
- The static `STRUCTURE.md` / `treegen` workflow has been retired.
- Repository structure discovery is now dynamic through Serena, GitNexus, normal file navigation, `rg` and `ast-grep`.
- Git hooks are simplified to the GitNexus post-commit contract only.
- The repository has been operationally cleaned so `main` is the single active branch.
