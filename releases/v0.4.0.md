# v0.4.0 - Claude Code and Herdr workstation bootstrap

**Date:** 2026-10-23
**Previous Release:** v0.3.0

## Highlights

- Provision the native, stable Claude Code CLI automatically on Ubuntu/WSL2 when missing, without replacing a working installation, changing authentication, or editing shell startup files.
- Converge Herdr and the detected Claude, Codex, OpenCode and Cursor integrations from the standard `dotfiles-update` tooling phase.
- Preserve active Herdr sessions by skipping runtime upgrades during routine updates; `make install-herdr` remains the explicit update path.
- Add `make install-ai-workspace` to provision just Claude Code and Herdr, with idempotent and dry-run behavior, separate from the full bootstrap.
- Document replication on the second WSL workstation and maintain separation from Windows-native terminal management.
